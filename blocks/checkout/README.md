# checkout

The shop checkout (`/us/en/shop/checkout`): contact and delivery details,
payment method (Credit / debit card, UPI, PayPal, Cash on delivery) and
"Place order", followed by an order confirmation with an order number.

**Demo only:** no payment is taken, no card numbers are asked for and nothing
is sent anywhere — the order number is made up in the browser and the cart is
emptied. Guest checkout; signed-in members pay the member price.
